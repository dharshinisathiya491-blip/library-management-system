# Library Management System

## About the Project
A simple GUI-based Library Management System developed using Python, Tkinter, and SQLite.

This application allows users to manage book records through a graphical user interface.

## Features
- Add new book records
- View all books
- Search books by ID
- Delete book records
- Store data using an SQLite database

## Technologies Used
- Python
- Tkinter
- SQLite

## Requirements
- Python 3 installed
- Tkinter (usually included with standard Python installations)
- SQLite (included with Python's `sqlite3` module)

## How to Run
1. Clone or download this repository.
2. Open a terminal in the project folder.
3. Run the command:

```bash
python library_management.py
```

## Project Type
Beginner-level Python GUI and database project.
